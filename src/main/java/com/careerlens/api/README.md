# CareerLens – AI Career & Job Management System

CareerLens is a career management application built using React, Spring Boot, and MySQL.

## Features

- User login and authentication using JWT
- Resume upload and skill extraction
- Job listings and recommendations
- Skill-based job match percentage
- Missing skills identification
- Job application submission
- Application status tracking

## Technologies Used

- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL 8
- Maven
- React.js

## Backend Setup

### Prerequisites

- Java JDK 21
- MySQL 8

### Run the Application

On Windows PowerShell, run:

```powershell
.\mvnw.cmd spring-boot:run
```

Backend URL: `http://localhost:8080`

Before starting the backend, configure the local database connection and JWT settings.
